1. Overview & Philosophy

This document specifies the complete UI/UX design for the Cole Street Home Assistant dashboard. It serves as the single source of truth for the executor (Google Antigravity) to implement the dashboard from the accompanying dashboard.yaml file.

Core Principles

  • Glassmorphism dark theme — Translucent cards with backdrop blur over a deep navy background (#0b0d14). Every card uses the same glass treatment for visual consistency.
  • Minimal scroll on mobile — The home view prioritizes at-a-glance information. Room details live in dedicated subviews, not pop-ups.
  • Subview architecture — Rooms are full subviews (not Bubble Card pop-ups) for better navigation, back-button support, and deep-linking.
  • Mushroom-first, Bubble-where-needed — Mushroom cards handle 90% of UI. Bubble Card is used only for the bottom navigation bar and the washer progress card.
  • Real entity IDs throughout — No placeholders. Every card references actual entities from the Cole Street HA instance.

6. Component Patterns

Glass Card (Home page)

YAML anchor &glass_card — applied via card_mod on each Mushroom card:

background: rgba(255, 255, 255, 0.06)
backdrop-filter: blur(25px) saturate(120%)
border-radius: 24px
border: 1px solid rgba(255, 255, 255, 0.08)
border-top: 1px solid rgba(255, 255, 255, 0.2)
box-shadow: 0 8px 24px rgba(0, 0, 0, 0.1)

Glass Card (Subview)

YAML anchor &subview_card — slightly more transparent:

background: rgba(255, 255, 255, 0.04)
backdrop-filter: blur(30px) saturate(140%)
border-radius: 20px
border: 1px solid rgba(255, 255, 255, 0.04)
border-top: 1px solid rgba(255, 255, 255, 0.12)

Section Header (transparent)

YAML anchor &section_header — a mushroom-template-card stripped of all backgrounds, acting as a pure text label with icon. All ::before/::after pseudo-elements are killed to prevent theme glass layers from leaking through.

Room Tile

Square mushroom-template-card with:

  • ::before pseudo-element loads a background image from /local/ with gradient mask (fade from top to transparent at 60%)
  • Icon positioned bottom-left in a quarter-circle shape
  • Room name positioned bottom-right with text shadow
  • Tap action navigates to the room's subview

Washer Progress Card

A custom:bubble-card button with large-2-rows layout. The ::after pseudo-element renders a dynamic progress bar computed from washer_total_time and washer_remaining_time_2. The icon spins when the washer is actively running (not idle/paused).

Shutdown Button

A mushroom-template-card with red-tinted glass, nested inside the System section. Accidental-press resistant: tap does nothing; double-tap fires the shell command with a browser confirmation dialog. Hold also does nothing.

Infrastructure Host Card

A custom:button-card with direct styling (not Mushroom chips). Key design constraints:

  • Glass fill: rgba(255,255,255,0.04), blur(16px), border-radius: 22px — intentionally more subdued than room cards
  • No pill/chip backgrounds anywhere on nested elements — action buttons and stat chips sit directly on the card's glass, not inside their own container
  • Top-right overlay: amber mdi:restart + red mdi:power (14px icons, ~20px hit target, ~55% opacity). Both are double-tap only with confirmation dialog; tap and hold are no-ops. Calls shell_command.host_power_control with service_data: host/action
  • Online status: green text when binary_sensor.{host}_online is on, amber when off
  • core-01 exception: replaces online/offline status with CPU + Memory stat chips (icon + label, transparent background), reusing sensor.system_monitor_*

Infrastructure Cluster Shutdown

A compact round red icon-button (44px) in the "Hosts" header row, aligned far right. Double-tap → shell_command.super_power_button with confirmation dialog. Same accidental-press resistance as the Home view shutdown: tap and hold are no-ops.

7. Responsive Behavior

BreakpointBehavior
< 800px (mobile)Single column. All grids collapse to 1 column via --grid-card-column-count: 1. Room tiles remain 2×2. Bottom nav scrolls horizontally if needed. Content padded 80px at bottom for nav clearance.
≥ 800px (desktop)2-column grid on Home view: left column (data) + right column (rooms, 440px max). Subviews stay single-column at 900px max-width. Energy chart grids show 2 columns.

Scrollbar

Subtle thin scrollbar: scrollbar-width: thin; scrollbar-color: rgba(255,255,255,0.08) transparent. WebKit: 4px wide, transparent track, 8% white thumb with 4px radius.

Safe Area

Bottom nav uses padding-bottom: env(safe-area-inset-bottom, 0px) for iPhone notch/home indicator.

8. Implementation Notes

Installation Steps

  1. Install all HACS custom cards listed in Section 2.
  2. Place room backdrop images in /config/www/.
  3. Go to Settings → Dashboards → Add Dashboard. Set URL to cole-street.
  4. Open the dashboard, click the 3-dot menu → Raw Configuration Editor.
  5. Paste the entire contents of dashboard.yaml.
  6. Save. Clear browser cache if glass styles don't appear immediately.

YAML Anchors

The YAML uses anchors (&) and aliases (*) extensively to DRY the glass card styles. Key anchors:

  • &glass_card — weather card glass
  • &glass_card_sm — standard Mushroom card glass
  • &section_header — transparent section label
  • &subview_card — subview card glass
  • &subview_header — subview section label
  • &chip_bar — breadcrumb chip styling
  • &energy_chart_card — stack-in-card wrapper
  • &energy_inner — transparent inner card
  • &mini_graph — mini-graph transparent style
